# ⛏ MinePulse 1.0 — Telegram-бот Minecraft-серверов

Бот для **Java Edition + Bedrock Edition** с каталогом, статусом серверов,
избранным, уведомлениями и платным продвижением через **Telegram Stars**.

**Язык:** Python 3.11+. **Зависимости:** только стандартная библиотека Python.
**База:** SQLite (автоматически создаётся). **Связь с Telegram:** long polling, HTTPS.
**Проверка Minecraft:** собственные TCP/UDP-клиенты протоколов Java/Bedrock, без сторонних API.

> Это самостоятельный исходный проект, а не уже опубликованный бот.
> Укажи **свой** токен @BotFather и запусти программу.

## ✅ Что работает в 1.0

- 🟢/🔴 Проверка статуса Java (новый 1.7+ Server List Ping, fallback для старых Java) и Bedrock (RakNet UDP pong).
- Поиск по имени/IP, категории, фильтр редакции, сортировка с платным продвижением и постраничная навигация.
- Добавление серверов, защита от дубликатов, лимит 5 публикаций на человека (настраивается).
- Избранное, отдельное **согласие** на уведомления и сообщения о смене состояния сервера.
- Фоновая проверка раз в 180 секунд; две подряд ошибки нужны, чтобы считать ранее работавший сервер упавшим.
- Кнопка ручной проверки с ограничением частоты; команда `/check` для сервера, не добавленного в каталог.
- Платный приоритет в каталоге на 7 дней; полная цепочка Stars `sendInvoice → pre_checkout_query → successful_payment`.
- Хранение Telegram charge ID и предотвращение повторного начисления одной оплаты.
- Условия покупки с подтверждением, `/paysupport` и сообщения администратору, команда возврата Stars.
- Администратор может удалять публикации, отвечать пользователям и делать возвраты.
- Защита от проверок localhost, LAN и внутренних IP, даже когда публичный домен указывает на них.
- Работает на Windows, Linux, Docker и VPS, если разрешено подключение к серверам по TCP/UDP.

## 🖥 Windows — запуск

1. Установи **Python 3.11 или новее** с официального сайта `https://python.org` (при установке включи добавление Python в PATH).
2. Распакуй ZIP с проектом в отдельную папку.
3. Открой в Telegram **@BotFather**, введи `/newbot` и создай бота. Скопируй выданный токен.
4. Дважды нажми `start.bat`. При первом запуске появится файл `.env` и откроется «Блокнот».
5. Замени `BOT_TOKEN` своим токеном. Укажи `ADMIN_IDS` — свой числовой Telegram ID (можно узнать через @userinfobot). Сохрани файл и закрой «Блокнот».
6. Если скрипт не запустился автоматически после редактирования, запусти `start.bat` ещё раз.
7. Открой своего Telegram-бота и отправь `/start`.

**Важно:** Пока окно программы работает, бот работает. Чтобы бот работал круглосуточно — оставь компьютер включённым или размести его на VPS.

## 🐧 Linux / VPS

```bash
unzip MinePulse-1.0.zip -d MinePulse
cd MinePulse
cp .env.example .env
nano .env
python3 -m minepulse
```

В `BOT_TOKEN` вставь токен @BotFather. В `ADMIN_IDS` укажи хотя бы один Telegram ID.
Для постоянной работы используй systemd или Docker.

## 📱 Android / Termux — переход с ZIP на GitHub

MinePulse работает в Termux с обычным Python. **Перед переходом останови старого бота** сочетанием `CTRL+C`, чтобы безопасно перенести SQLite.

```sh
pkg install python git -y
git clone https://github.com/din820553-debug/MinePulse.git ~/MinePulse-GitHub
cp ~/MinePulse/.env ~/MinePulse-GitHub/.env
cp -r ~/MinePulse/data ~/MinePulse-GitHub/data 2>/dev/null || true
cd ~/MinePulse-GitHub
python -m minepulse
```

Старую папку `~/MinePulse` не удаляй — она остаётся резервной копией.
Если каталог `data` ещё не существует, это нормально: бот создаст новую базу.

Для обновления бота: останови его (`CTRL+C`) и выполни:

```sh
cd ~/MinePulse-GitHub
git pull --ff-only
python -m unittest discover -s tests -q
python -m minepulse
```

`.env` и `data/` исключены из Git с помощью `.gitignore`, поэтому `git pull`
не заменяет токен, пользователей, избранное и историю платежей. Однако **перед обновлением**
лучше вручную сохранить копию `.env` и `data/` в другом месте. Не запускай один
и тот же бот одновременно из старой и новой папки: у Telegram long polling
может возникнуть конфликт.

Android может останавливать фоновый Termux. Для настоящих 24/7 лучше VPS.

Данные хранятся в постоянном Docker-томе `minepulse_data`.

## ⚙ Настройки `.env`

| Переменная | Значение | Назначение |
|---|---|---|
| `BOT_TOKEN` | токен от BotFather | обязательно |
| `ADMIN_IDS` | `123456789` | твой Telegram ID; без него платежи отключены |
| `DATABASE_PATH` | `data/minepulse.db` | база SQLite |
| `CHECK_INTERVAL` | `180` | интервал проверки в секундах, минимум 60 |
| `CHECK_CONCURRENCY` | `12` | параллельные сетевые проверки |
| `MAX_SERVERS_PER_USER` | `5` | лимит публикаций |
| `PROMO_STARS` | `50` | цена продвижения **в Stars**, не в рублях |
| `PROMO_DAYS` | `7` | срок продвижения |

### Команды админа

- `/admin` — административная справка.
- `/delete 123` — удалить сервер из каталога (ID 123).
- `/reply 123456789 Текст сообщения` — ответить в поддержку пользователю.
- `/refund 123456789 TELEGRAM_CHARGE_ID` — вернуть Stars через Telegram и сократить активное продвижение.

Команды админа доступны **только** ID из `ADMIN_IDS`.

## 💫 Как устроен заработок

В карточке сервера, который пользователь сам добавил, появится кнопка
**«⭐ Продвижение: 50 Stars»**. Владелец публикации должен сначала принять
условия, затем получает счёт в Telegram. После подтверждённой оплаты
сервер поднимается над бесплатными результатами каталога на 7 дней.
Продление добавляется к ещё не истёкшему сроку.

**До получения первых реальных платежей:**

1. Убедись, что в `.env` указан `ADMIN_IDS`, иначе покупки блокируются для безопасности пользователей.
2. Протестируй платежи в официальной тестовой среде Telegram Stars.
3. Заполни собственные юридические условия, процедуру модерации и обработки персональных данных.
4. Обеспечь доступную поддержку `/paysupport`, резервное копирование платежных данных и возможность возврата.

Это цифровая услуга внутри Telegram: для неё используется **XTR / Telegram Stars**.
Стоимость в рублях зависит от курса и способа получения Stars пользователями.
**Никакого гарантированного дохода** нет: прежде нужны реальные пользователи и серверы в каталоге.

## 🛡 Безопасность

- Токен в `.env`, не добавляется в Git (`.gitignore`). Никому его не пересылай.
- DNS и IP проверяются на публичность; соединение идёт к проверенному IP, без повторного DNS-запроса.
- HTTPS-запросы к Telegram выполняются через библиотеку Python `urllib`.
- Обрабатываются подтверждённые Telegram `successful_payment` события, а не сообщения пользователей вида «я оплатил».
- Подключение к внутренним/private адресам запрещено. Настоящий владелец бота должен дополнительно использовать сетевые ограничения контейнера/VPS от злоупотреблений.
- Бот не собирает банковские карты, пароли от Microsoft/Minecraft или пароли Telegram.
- Пользователи не проверяются на **фактическое владение** добавляемым Minecraft-сервером. Не выдавай авторство публикации за подтверждённое право собственности; добавь верификацию перед публичным запуском крупного каталога.

## ⚠ Ограничения версии 1.0

- Бот использует стандартные протоколы проверки. Это **не гарантия**, что ответит любой Minecraft-сервер любого релиза: некоторые сети скрывают сведения, блокируют запросы или используют нестандартные прокси.
- Java **DNS SRV** (`_minecraft._tcp`) пока не обрабатывается: для таких серверов укажи реальный адрес/порт сервера, на который ведёт SRV.
- Мини-приложения Telegram (Mini App), сайт-каталог, аватары серверов, отзывы и графики онлайна — планы следующих версий, **не включены** в 1.0.
- История аптайма пока не ведётся: сохраняется последнее состояние и время проверки.
- Для Telegram/Stars нужен доступ в интернет и реальный токен. Автоматические тесты проходят на локальных протокольных имитаторах; они не подтверждают реальную покупку или соединение с конкретными публичными серверами.
